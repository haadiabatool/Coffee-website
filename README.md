# ☕ ROAST & ROOT — Coffee Shop Website

ROAST & ROOT is a modern, responsive coffee shop website designed to create a warm and inviting digital experience for coffee lovers. It combines an elegant café-inspired aesthetic with rich coffee tones, carefully presented menu items, and smooth animations.

## ✨ Features

 Responsive Design: Optimized for desktop, tablet, and mobile devices.

 Hero Section: A welcoming introduction with engaging visuals and clear calls to action.

 Signature Coffee Menu: Showcases coffee selections with descriptions and prices.

 Why Choose Us: Highlights quality beans, fresh roasting, careful preparation, and a cozy atmosphere.

 Our Story: Shares the brand's passion for quality coffee and meaningful everyday moments.
